# 8 Bit Sewer Tale

The start of a JavaScript text-based adventure game. A page shows a location's title and description and has a box for typing commands. Locations are JSON files in [locations/](locations/) and objects are in [objects/](objects/).

## Status

June 2015 prototype. Only the intro location is loaded, and typed commands are not handled yet.

## Run

Serve the folder with any static web server (the page loads its data with requests, so opening the file directly may not work) and open `index.html`.
